# ByteSpace

Landing page along with login and signup page for the ByteSpace course platform, built from the
[Figma design](https://www.figma.com/design/26TBgRjmpuxudcErJsHUfy/ByteSpace-New-Check-website?node-id=0-1&p=f&t=eQOrqJmq6rMG5b6L-0) with
React, TypeScript, Vite, Tailwind CSS v4 and TanStack Router.

The page is static for now: there's no search, filtering or form logic yet.

## Getting started

```bash
npm install
npm run dev
```

Routes: `/` (home), `/login`, `/signup`.

## Project structure

```
src/
├── main.tsx                   # mounts <RouterProvider>
├── router.ts                  # router instance + type registration
├── routeTree.gen.ts           # generated by the TanStack Router Vite plugin (don't edit)
├── routes/                    # file-based routes — one thin file per URL
│   ├── __root.tsx             #   app shell for every page
│   ├── index.tsx              #   /
│   ├── login.tsx              #   /login
│   └── signup.tsx             #   /signup
├── pages/                     # page UI, grouped by page
│   ├── home/                  #   HomePage + its sections/ and data.ts
│   └── auth/                  #   LoginPage, SignupPage + shared components/ and data.ts
├── components/                # shared across pages
│   ├── layout/                #   Header, Footer, Container, DesignCanvas, RootLayout
│   ├── ui/                    #   primitives: Button, Logo, StarIcon, AvatarStack, Ornament, …
│   ├── forms/                 #   TextField
│   ├── cards/                 #   CourseCard, CategoryCard, TestimonialCard
│   └── widgets/               #   floating info cards (progress, happy students, …)
├── data/                      # shared domain data (courses)
├── constants/                 # asset paths, navigation links
├── types/                     # shared TypeScript types
└── index.css                  # Tailwind import, fonts, design tokens (@theme)
```

### Adding a page

1. Build the UI in `src/pages/<page>/` (page-only sections, components and data live there too).
2. Add a route file, e.g. `src/routes/courses.tsx`:

   ```tsx
   import { createFileRoute } from '@tanstack/react-router'
   import CoursesPage from '@/pages/courses/CoursesPage'

   export const Route = createFileRoute('/courses')({ component: CoursesPage })
   ```

3. With `npm run dev` running, the route tree regenerates automatically and `<Link to="/courses">`
   becomes type-checked.

Imports use the `@/` alias for `src/` (configured in `vite.config.ts` and `tsconfig.app.json`).

### Design tokens

Colours, fonts and the type scale from Figma live in `src/index.css` under `@theme`, so they
are available as regular utilities, e.g. `bg-persian-blue-800`, `text-electric-lime-400`,
`text-heading-m`, `text-body-l`, `text-label-xs`.

Fonts: **Poppins** (Google Fonts), **Satoshi** and **Clash Display** (Fontshare), loaded in
`index.html`.
